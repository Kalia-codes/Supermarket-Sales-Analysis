# Supermarket Sales Analysis

## Project Overview

Supermarket Sales Analysis is a Data Analytics project that analyzes
500 supermarket sales transactions to identify useful business insights.

The project analyzes:

- Product performance
- Category performance
- Branch performance
- Customer behavior
- Payment methods
- Customer ratings

The analysis was performed using Python, Pandas, NumPy, and Matplotlib.

---

## Project Objective

The main objective is to analyze supermarket sales data and convert
the data into meaningful business insights that can support better
decision-making.

The project follows these main steps:

1. Load the sales dataset
2. Check missing and duplicate values
3. Analyze sales data
4. Calculate totals, counts, and averages
5. Group data by different business dimensions
6. Create charts
7. Generate business recommendations

---

## Dataset

The dataset contains 500 supermarket transactions.

### Dataset Columns

| Column | Description |
|---|---|
| Transaction ID | Unique transaction identifier |
| Product | Product purchased |
| Category | Product category |
| Branch | Store branch |
| City | Branch city |
| Customer Type | Member or Normal customer |
| Quantity | Quantity purchased |
| Unit Price | Price per unit |
| Payment Method | Payment method used |
| Rating | Customer rating |
| Sales | Total transaction sales |

Sales are calculated using:

```text
Sales = Quantity X Unit Price
